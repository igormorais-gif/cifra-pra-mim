# Roadmap do Cifra pra Mim

## Etapa 1 — Base (este protótipo)
- [x] Documentar módulos e objetivos pedagógicos.
- [x] Construir uma página navegável e responsiva sem dependências.
- [x] Mostrar exemplo de Adaptando Pontas no teclado.
- [x] Criar exemplo sonoro da cadeia G → G°7.
- [x] Criar o repositório remoto e publicar o primeiro commit.

## Etapa 2 — Motor harmônico
- [ ] Representar acordes com graus, alterações, inversões, baixo e notas omitidas.
- [ ] Criar testes unitários dos nomes de notas e dos intervalos.
- [ ] Validar regras de substituição de vozes antes de automatizar o processo.
- [ ] Separar fundamental harmônica de baixo em acordes com barra.

## Etapa 3 — Teclado
- [ ] Gerar Formas Originais e opções de Adaptando Pontas.
- [ ] Preservar exatamente o primeiro acorde das Formas Originais.
- [ ] Indicar notas da mão esquerda, direita, grau e ponta.
- [ ] Aplicar como regra inicial ponta com deslocamento máximo de dois semitons entre acordes sucessivos, oferecendo exceções conscientes.
- [ ] Estender para sétimas, sus2/sus4, nonas, alterações de quinta e 13as com as regras autorais revisadas.

## Etapa 4 — Cavaquinho
- [ ] Mapear afinação e digitações conferidas fisicamente.
- [ ] Exibir diagramas de posição, grau por corda e arpejo.
- [ ] Organizar exemplos por forma de origem.
- [ ] Destacar a nota que se move em cada transição cromática.

## Etapa 5 — Entrada de músicas e publicação
- [ ] Criar importação de progressões escritas pelo usuário.
- [ ] Estudar formatos de entrada compatíveis e autorizados; não presumir permissão de copiar repertórios de terceiros.
- [ ] Validar acessibilidade, interface para celular e eventuais requisitos de hospedagem.
